


## Task 1: Calculate Factorial Using a Function

### Problem Description
This program calculates the factorial of a given number using a user-defined function.

### Functionality
The program:
1. Defines a function named `factorial` that takes a number as an argument.
2. Calculates the factorial using a loop or recursion.
3. Returns the calculated factorial value.
4. Calls the function with a sample number and prints the output.

### Expected Output 
Enter a number:5
Factorial of 5 is 120

## Task 2: Mathematical Calculations Using math Module

### Problem Description
This program performs various mathematical calculations using Python’s built-in `math` module.

### Functionality
The program:
1. Asks the user to enter a number.
2. Uses the `math` module to calculate:
   - Square root of the number
   - Natural logarithm (log base e) of the number
   - Sine of the number (in radians)
3. Displays the calculated results on the screen.

### Expected Output
Enter a number:25
Sqaure root: 5.0
Logarithmic: 3.2188758248682006
Sine:-0.13235175009777303
